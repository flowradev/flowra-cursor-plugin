# Flowra for Cursor

One MCP server for your apps' tools and your own custom tools, plus hosted AI agents and workflows with approval gates and a run ledger.

## What you get
- Connect your apps once with OAuth and use their tools from Cursor. Browse toolkits at https://flowra.dev/toolkits
- Add your own custom tools and call them from the same server.
- Run hosted AI agents and workflows, with human approval before sensitive actions and a ledger of every run.

## Install
This plugin adds the Flowra remote MCP server:

```json
{ "mcpServers": { "flowra": { "url": "https://mcp.flowra.dev/mcp" } } }
```

On first use Cursor opens Flowra's sign-in. No API keys go in this config.
